# Acme Information Security Policy

## Passwords
Passwords must be at least fourteen characters. Reuse of any of the
previous ten passwords is blocked. Password rotation is no longer
mandatory on a fixed schedule; rotation is required only after a
suspected compromise.

## Multi-factor authentication
MFA is mandatory for all staff. Hardware security keys are required for
anyone with production database access. SMS is not an accepted second
factor.

## Device encryption
All laptops must have full-disk encryption enabled before being issued.
Lost or stolen devices must be reported to the security team within four
hours of discovery.

## Incident reporting
Suspected security incidents go to security@acme.example immediately.
Do not investigate a suspected phishing email yourself; forward it and
delete it.
